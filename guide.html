1. 처음 시작하기

  1. class-site 폴더의 index.html 을 더블클릭하면 브라우저에서 사이트가 열립니다. 별도 프로그램이나 서버가 필요 없습니다.
  2. 오른쪽 위 🔒 자물쇠를 누르고 기본 비밀번호 admin2026 을 입력하면 관리자 화면이 열립니다.
  3. 가장 먼저 [설정 파일] 탭 → 관리자 비밀번호 변경에서 비밀번호를 바꾸고, config.js 내려받기로 받은 파일을 사이트 폴더의 config.js 와 바꿔 주세요.
  4. 교수자 프로필(영어)·이메일·사진, Zoom 수업 입장 주소(schedule.onlineLink), 일정을 실제 정보로 고칩니다. (4. 내용 고치기)
  5. 실제 수업에서 수강생 데이터를 모으려면 운영 모드 연결을, 인터넷에 올리려면 인터넷에 올리기를 따라 주세요.
💡 사진은 class-site/images/instructor.jpg 로 넣으면 바로 보입니다. (images 폴더를 새로 만드세요. 세로 4:5 비율 권장)

4. 내용 고치기

방법 A — 관리자 화면에서 (추천)

  1. 관리자 화면 → [사이트 정보] 또는 [섹션 내용] 탭에서 왼쪽 목록의 항목을 고릅니다.
  2. 글을 고치고, 목록 항목은 ↑ ↓ 로 순서를 바꾸거나 ✕ 로 지우고 + 추가로 늘립니다.
  3. 저장하고 적용을 누르면 지금 쓰는 브라우저에 바로 반영되어 확인할 수 있습니다.
  4. 마음에 들면 [설정 파일] → config.js 내려받기를 누르고, 받은 파일로 사이트 폴더(또는 인터넷에 올린 사이트)의 config.js 를 바꿉니다. 이렇게 해야 모든 방문자에게 반영됩니다.
⚠ 화면에서 고친 내용은 처음엔 그 브라우저에만 저장됩니다. 다른 컴퓨터·수강생에게도 보이게 하려면 반드시 4번(config.js 바꾸기)을 해 주세요. 관리자 화면에서 자물쇠 옆에 주황색 점이 보이면 '이 브라우저에 수정본이 적용 중'이라는 뜻입니다.

방법 B — config.js 를 직접 고치기

config.js 를 메모장(또는 VS Code)으로 열어 따옴표 안의 글자를 고치고 저장합니다. 항목을 늘릴 때는 { ... } 묶음을 복사해 쉼표로 이어 붙이세요. 날짜는 "2026-09-01", 마감은 "2026-10-05 23:59" 형식입니다.

자주 고치는 곳

  • 학기 일정: schedule.startDate(1주차 날짜)만 바꾸면 15주 날짜와 달력이 자동으로 바뀝니다. 휴강일은 schedule.holidays 에 넣으면 그 주가 다음 주로 밀립니다.
  • 과제 마감: 각 주차의 assignment.due. 과제가 없는 주는 assignment 를 지우면 됩니다.
  • 섹션 순서·숨기기: order 목록의 순서를 바꾸거나 이름을 지웁니다. 메뉴는 menu.
💡 잘못 고쳐서 화면이 깨지면 주소 끝에 ?reset-config 를 붙여 열어 보세요. (예: index.html?reset-config) 이 브라우저의 수정본이 지워지고 원래 config.js 로 돌아갑니다.

5. 명단 · 공지 · 내역 관리

수강생 명단 등록

  1. 엑셀에서 학번 · 이름 · PIN 세 열을 선택해 복사합니다. (PIN 열이 없으면 자동 생성)
  2. 관리자 화면 → [수강생 명단] → 입력칸에 붙여 넣고 붙여 넣은 내용 추가를 누릅니다.
  3. 표에서 확인·수정한 뒤 명단 저장을 누릅니다. 이후 수강생은 학번·이름·PIN 으로 로그인합니다.
  4. PIN 은 수업 시간에 개별로 안내하세요. 명단 내려받기로 PIN 목록을 받을 수 있습니다.

수강 신청을 받은 경우 [수강 신청] 탭의 신청자를 명단에 추가로 한 번에 옮길 수 있습니다.

출석

수강생은 수업이 있는 날(달력의 수업일)에만 출석 버튼을 누를 수 있습니다. 운영 모드에서는 구글 서버가 한국 시간으로 날짜를 다시 확인합니다.

엑셀로 받기

[출석]·[과제]·[수강 신청] 탭 오른쪽 위 엑셀로 내려받기를 누르면 날짜가 붙은 CSV 파일이 저장됩니다. 운영 모드에서는 연결된 구글 시트에서도 같은 내용을 볼 수 있습니다.

7. 운영 모드 연결 (구글 시트, 무료)

  1. 구글 드라이브에서 새 스프레드시트를 만들고, 과제 파일을 모을 폴더도 하나 만듭니다.
  2. 스프레드시트 메뉴 [확장 프로그램] → [Apps Script]를 엽니다.
  3. backend/google-apps-script.gs 내용을 전부 복사해 붙여 넣습니다.
  4. 맨 위 설정을 고칩니다.
    • DRIVE_FOLDER_ID: 과제 폴더 주소 drive.google.com/drive/folders/이부분
    • CLASS_DATES: 수업 날짜 15개 (사이트 '주차별 강의' 날짜와 같게)
    • ADMIN_SALT, ADMIN_HASH: 관리자 비밀번호를 바꿨다면 바꿀 때 화면에 표시된 값
  5. 함수 목록에서 setup 을 고르고 [실행] → 권한을 승인합니다. 시트에 탭들이 생깁니다.
  6. [배포] → [새 배포] → 톱니바퀴에서 웹 앱 선택 → 실행: 나, 액세스: 모든 사용자 → [배포].
  7. 표시된 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사해 config.js 의 backend: { url: "여기" } 에 붙여 넣습니다.
  8. 사이트를 새로고침하면 '체험 모드' 안내가 사라지고 운영 모드로 동작합니다. 관리자 화면에서 명단을 등록하세요.
💡 Apps Script 코드를 고친 뒤에는 [배포] → [배포 관리] → ✏️ → 버전: 새 버전 → 배포를 해야 반영됩니다. (주소는 그대로 유지됩니다)

8. 인터넷에 올리기 (배포)

이 사이트는 파일만 있으면 되는 '정적 사이트'라 어디에나 무료로 올릴 수 있습니다. backend 폴더는 올리지 않아도 됩니다.

방법 A — Netlify Drop (가장 쉬움, 약 1분)

  1. app.netlify.com/drop 에 접속해 무료 계정으로 로그인합니다.
  2. class-site 폴더를 브라우저 화면에 끌어다 놓습니다.
  3. 잠시 뒤 https://○○○.netlify.app 주소가 생깁니다. 이 주소를 수강생에게 안내하세요.
  4. 내용을 고친 뒤에는 사이트 관리 화면의 Deploys 에 폴더를 다시 끌어다 놓으면 같은 주소로 바뀝니다.

방법 B — GitHub Pages

  1. GitHub 에 새 저장소(Public)를 만들고 Add file → Upload files 로 class-site 안의 파일을 모두 올립니다.
  2. 저장소 Settings → Pages 에서 Branch 를 main / (root) 로 정하고 Save.
  3. 몇 분 뒤 https://아이디.github.io/저장소이름/ 주소로 열립니다. 수정할 때는 config.js 를 다시 올리면 됩니다.

방법 C — 학교 홈페이지 · 웹호스팅 · LMS

FTP 나 파일 업로드가 되는 공간이라면 class-site 폴더의 파일을 그대로 올리면 됩니다. LMS 에는 사이트 주소를 링크로 걸어 두세요.

내용을 바꿀 때 (배포 후)

  1. 관리자 화면에서 고치고 저장하고 적용으로 확인
  2. [설정 파일] → config.js 내려받기
  3. 올린 사이트의 config.js 를 새 파일로 교체 (Netlify 는 폴더를 다시 끌어다 놓기)
💡 공지·명단·출석·과제는 운영 모드라면 구글 시트에 바로 저장되므로 다시 배포할 필요가 없습니다. 다시 배포가 필요한 것은 사이트 글·일정·메뉴 같은 설정뿐입니다.

9. 수강생에게 안내할 내용

  • 사이트 주소, 그리고 각자의 PIN (로그인: 학번 + 이름 + PIN)
  • 출석·과제 메뉴: 수업 당일 '지금 출석하기', 과제는 파일을 끌어다 놓고 '제출하기' (최대 10MB · pdf, docx, hwp 등)
  • 주차별 강의에서 학습 내용·참고 영상·과제 마감까지 남은 시간을 확인할 수 있음
  • 수업 달력에서 날짜를 누르면 그날 수업 내용이 나옴
  • 휴대폰에서는 오른쪽 위 ☰ 버튼으로 메뉴를 엽니다

10. 보안 · 개인정보 안내

  • 관리자 비밀번호는 코드에 그대로 적히지 않고 SHA-256 해시값으로만 저장됩니다. 기본 비밀번호(admin2026)는 반드시 바꿔 주세요. 짐작하기 어려운 8자 이상을 권장합니다.
  • 정적 사이트의 한계상, 화면 잠금은 '편리한 잠금 장치' 수준입니다. 운영 모드에서는 수강생 데이터(명단·출석·과제·신청서)를 구글 서버가 비밀번호를 다시 확인한 뒤에만 내보내므로, 실제 데이터는 서버 쪽에서 보호됩니다.
  • 체험 모드의 데이터는 각 브라우저에 저장됩니다. 공용 PC에서 시연한 뒤에는 브라우저의 사이트 데이터를 지워 주세요.
  • 수강 신청서에는 개인정보 수집 동의 항목이 있습니다. 학교 개인정보 지침에 맞게 문구를 고치고, 학기가 끝나면 시트 데이터를 정리하세요.
  • 성적처럼 민감한 정보는 이 사이트나 시트에 두지 마세요.

11. 문제 해결

증상해결
화면이 하얗게 나오거나 "config.js 를 불러오지 못했습니다"config.js 를 직접 고치다 쉼표·따옴표가 빠졌을 가능성이 큽니다. 마지막으로 고친 부분을 확인하거나, 관리자 화면에서 내려받은 config.js 로 바꾸세요.
관리자 화면에서 고친 뒤 화면이 이상함주소 끝에 ?reset-config 를 붙여 열면 원래대로 돌아갑니다.
다른 컴퓨터에서는 수정한 내용이 안 보임정상입니다. [설정 파일] → config.js 내려받기 → 사이트 파일 교체를 해 주세요.
비밀번호를 잊어버림config.js 의 admin 부분을 아래 기본값으로 되돌리면 비밀번호가 admin2026 이 됩니다.
admin: {
  salt: "rw-2026",
